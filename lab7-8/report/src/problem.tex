\CWHeader{Лабораторная работа \textnumero 7-8 \enquote{Булев поиск}}

Необходимо реализовать систему булева поиска над корпусом HTML-документов, собранных в рамках лабораторной работы №1. Требования к системе:

\begin{itemize}
    \item построить обратный (позиционный) индекс: для каждого терма хранить список пар \texttt{<doc\_id, позиция>}, а не только факт присутствия терма в документе;
    \item реализовать поисковые операции над индексом:
    \begin{itemize}
        \item \textbf{AND} --- пересечение списков документов (и проверка совпадения позиций при необходимости);
        \item \textbf{OR} --- объединение списков документов;
        \item \textbf{NOT} --- дополнение относительно полного набора документов корпуса;
        \item \textbf{Фразовый поиск} --- поиск точной последовательности термов с учётом позиций;
    \end{itemize}
    \item обеспечить сохранение индекса в бинарный файл и возможность загрузки без повторного построения;
    \item корректная работа с кириллическими символами в токенизаторе (проверка байтов UTF-8);
    \item корректный многотерминный \textbf{AND} (пересечение всех термов запроса).
\end{itemize}
